[ 01 // ARCHITECTURE ]

Native Audio Engine and Direct Hardware Access

An offline music player with a dedicated Rust audio engine, designed for responsive playback, flexible audio routing, and direct USB DAC communication without ads or telemetry.

[ 01 // USB AUDIO ROUTING ]

Direct USB DAC Communication

When connected to a supported USB DAC, Mobius can communicate with the device in user space using Android USB host APIs and libusb. This sends PCM audio frames directly to the DAC endpoint at the track native sample rate, bypassing shared system mixing.

ioctl(fd, USBDEVFS_CLAIMINTERFACE)

[ 02 // NATIVE RUST CORE ]

Dedicated Audio Thread in Rust

Audio decoding, ring buffer management, and DSP calculations run in native Rust outside the Dart garbage-collected heap. This isolates audio processing from UI rendering, reducing the risk of buffer underruns.

let transfer = libusb_alloc_transfer(16);

[ 03 // VOLUME CONTROL ]

64-Bit Float Volume Scaling

For USB DACs that lack hardware volume controls or UAC2 mixer endpoints, Mobius applies 64-bit floating-point volume scaling with a logarithmic taper, mapped to the phone physical volume buttons.

pcm = ((raw as f64) * gain).round()

[ 02 // SIGNAL FLOW ]

Shared System Audio vs Direct USB Routing

Audio on Android can be routed through the shared system mixer or directly to an external USB DAC endpoint.
